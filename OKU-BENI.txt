DryAlle Kuru Temizleme - Web Sitesi
========================================

Kaynak kod bu klasörde; site GitHub Pages üzerinden yayınlanır.

CANLI GELİŞTİRME (tüm sayfalarla çalışma):
   → baslat-dev-server.command dosyasını çift tıklayın
   → İlk kez ~1 dk bağımlılık kurulumu yapacak
   → Sonra http://localhost:4321 adresinde site açılır

YAYINA ALMA:
   → Değişikliği "astro-src" dalına gönderin (git push).
   → GitHub Actions otomatik derler, "astro-live" dalına atar,
     GitHub Pages dryallekurutemizleme.com adresinde yayınlar.
   → Elle deploy adımı YOKTUR. Detay: CLAUDE.md → Deploy Kurallari

YAPI:
   src/             Astro kaynak dosyaları
   public/          Statik varlıklar (font, ikon, görsel)
   config/          Site konfigürasyonu (site.config.json — tek otorite)
   dist/            Build çıktısı (npm run build sonrası, yayına giden)
